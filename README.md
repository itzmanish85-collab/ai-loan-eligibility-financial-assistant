# AI Loan Eligibility & Financial Guidance Assistant

An AI-native fintech product prototype combining deterministic loan calculations, loan-product recommendations, product analytics, and a local LLM-powered financial guidance assistant.

## Features

- Illustrative loan eligibility assessment
- EMI calculation
- Eligibility score and risk classification
- Synthetic loan-product recommendations
- AI-powered financial explanations
- Conversational AI assistant
- Product analytics dashboard
- Product funnel analysis
- A/B testing experiment design
- Local LLM using Ollama and Llama 3.2

## AI Architecture

User Input
→ Deterministic Financial Engine
→ Eligibility & EMI Calculation
→ Product Recommendation
→ AI Explanation Layer

The Python calculation engine handles financial calculations. The LLM is used only to explain the generated results and answer user questions.
